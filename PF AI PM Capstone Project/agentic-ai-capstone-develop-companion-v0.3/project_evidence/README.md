# Synthetic Project Evidence

Everything in this folder is fabricated for the CasaFlowAI capstone. Nothing is a real permit, professional record, photograph, address, contractor record, or municipal document.

The Develop MVP does not require inspection screenshots or a City portal integration. Inspection results are stored as source-stamped contractor attestations in `data/inspection_register.csv`.

Photos are optional. A photo never independently proves full activity completion, safety, code compliance, inspection approval, permit acceptance, or professional approval.
