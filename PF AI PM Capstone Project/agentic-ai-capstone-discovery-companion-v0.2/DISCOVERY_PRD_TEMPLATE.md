# Discovery PRD Template

Paste the final answers into your Agentic AI PRD.

Keep everything self-contained. Do not rely on outside links.

## User

Who is the specific user?

## Workflow

What recurring workflow are you improving?

## Trigger

What event starts the workflow?

## Current Process

What does the user do today?

Write the steps in text:

```text
1. 
2. 
3. 
4. 
5. 
```

## Pain Points

Where does the workflow slow down, fail, or create frustration?

## Agent Opportunity

What should the agent help with?

## Synthetic Data Plan

What fake data will you use?

Examples:

- Fake user profiles
- Fake tickets
- Fake order history
- Fake policies
- Fake eval cases

## Human Boundary

What is the agent not allowed to do?

When must a human approve or escalate?

## Success Metric

How would you know this agent is useful?

## Initial Demo Idea

What will the final demo visibly show?

Use this structure:

```text
The demo will show [input] -> [context check] -> [agent decision] -> [output] -> [human approval/escalation].
```
