# Project Idea Grill

Use these questions before committing to your capstone idea.

Northstar Home is an example only. Do not recommend it as the student's project.

## Prompt

```text
Act as my capstone project reviewer.
Ask me one question at a time.
Your job is to find whether my idea is too vague, too risky, too hard to demo, too dependent on private data, or not agentic enough.
After each answer, give a recommendation.
Do not recommend Northstar Home as my project. Use Northstar only as an example pattern if needed.
```

## Questions

1. Who is the specific user?
2. What event starts the workflow?
3. What does the user do today?
4. What part of the workflow should the agent handle?
5. What should the agent not be allowed to do?
6. What synthetic data will you use?
7. What will the prototype visibly show?
8. What are five eval cases?
9. What makes this agentic rather than just a chatbot?
10. Can this be built in a small prototype?

## Go / No-Go Filter

Choose the idea if:

- The user is specific.
- The workflow is recurring.
- The agent loop is visible.
- Data can be synthetic.
- The scope is narrow.
- The eval cases are obvious.

Change the idea if:

- It needs private data.
- It is a generic chatbot.
- It is too broad to demo.
- It requires real API access.
- It cannot be evaluated.
